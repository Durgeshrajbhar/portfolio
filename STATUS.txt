================================================================================
HOW TO DEPLOY
================================================================================

STEP 1: PUSH TO GITHUB
  $ git add .
  $ git commit -m "Ready for Vercel deployment"
  $ git push origin main

STEP 2: DEPLOY TO VERCEL
  1. Go to https://vercel.com/new
  2. Click "Import GitHub Repository"
  3. Select your portfolio repository
  4. Click "Deploy"
  5. Wait for build to complete (should be ~2 minutes)

STEP 3: SET UP BLOB STORAGE
  1. Vercel Dashboard
  2. Settings → Storage → Blob
  3. Create/add Blob storage
  4. BLOB_READ_WRITE_TOKEN auto-configured
  5. Optionally redeploy (auto-deployed)

STEP 4: TEST LIVE SITE
  1. Visit https://[project-name].vercel.app
  2. Go to /about
  3. Test newsletter form
  4. Test contact form
  5. Check /admin for submissions

TOTAL TIME: ~5-10 minutes

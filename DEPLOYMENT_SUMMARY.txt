HOW TO DEPLOY
================================================================================

STEP 1: Push to GitHub
  $ git add .
  $ git commit -m "Ready for Vercel deployment"
  $ git push origin main

STEP 2: Deploy to Vercel
  1. Go to https://vercel.com/new
  2. Click "Import GitHub Repository"
  3. Select your portfolio repo
  4. Click "Deploy"
  5. Wait for build to complete (~2 minutes)

STEP 3: Set Up Blob Storage
  1. In Vercel dashboard, go to Settings → Storage
  2. Click "Create Blob Store" or "Add Integration"
  3. Follow the setup wizard
  4. BLOB_READ_WRITE_TOKEN will be auto-configured
  5. Redeploy or trigger new deployment

TOTAL TIME: ~5-10 minutes

TROUBLESHOOTING
================================================================================

❌ Forms not saving?

   → Verify Blob integration is enabled

❌ Admin page shows no data?
   → Refresh the page
   → Check browser console (F12) for errors
   → Verify API endpoints are responding

❌ Deployment failed?
   → Check Vercel build logs
